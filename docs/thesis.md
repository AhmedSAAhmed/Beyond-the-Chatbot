# Two-year thesis: after the chatbot

Chat became the default AI interface because it was the cheapest thing to build, not because it fits work. A chat box hands the hardest part back to the person: knowing what to ask. A dashboard does the same with charts, because someone still has to notice that a bar got taller and decide what it means. In both, the system holds the data and the person does the thinking.

By 2028 the interfaces that win will reverse that. The system reads everything, infers intent, and presents a short, ranked list of decisions, each one already drafted: what is happening, the evidence, the proposed action, what it costs, and what else it might be. The person's job moves from operating software to judging proposals. The unit of the interface stops being the screen or the conversation and becomes the decision.

Three patterns will define that shift. First, proposals instead of answers: the AI drafts the refund batch, the reply in each customer's language, and the knowledge fix, and a person approves, edits or rejects with one action. Second, visible uncertainty: when the system is unsure it asks one sharp question instead of guessing, and every proposal carries its next-best reading, so "not this" is a single click that teaches the system something. Third, reversibility and receipts: every action can be undone for a short window and is logged with exactly what was approved, which is what makes delegation safe enough to grant.

Chat will not disappear; it becomes the fallback for the rare case the system did not anticipate. The products that still open with a blank text box will feel the way command lines feel to most people today: powerful, and the wrong default.
