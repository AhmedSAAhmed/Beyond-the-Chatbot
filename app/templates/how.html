recovery paths

Live inference, not hardcoded flows

Live path
Every message sent from the "Send a customer message" drawer (or POST /webhooks/doo) is classified by the model and routed to the cluster of its nearest neighbour in real time. Two similar new complaints create an agent-initiated card.
Models
A pool of free-tier models, Groq first (gpt-oss-120b, qwen3.8-27b), Gemini as fallback; a rate-limited model cools down and the next answers. Grouping needs no second model: the issue phrase the LLM writes (in English, whatever the customer's language) is vectorised locally, so the live path has no embedding quota to run out of.

Safety
Customer text only ever goes in the user turn as data. Injection attempts are flagged by rules and by the model, excluded from evidence and drafts, and shown on the card. Money actions are capped in code, not in the prompt.
Each visitor
gets a private sandbox of the same shift, so nothing you approve changes anyone else's screen. "Restart shift" starts over.
