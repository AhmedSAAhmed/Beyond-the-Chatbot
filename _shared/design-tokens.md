# Design tokens (Navy theme)

Taken from the Navy theme by Lexington Themes (https://navy-astro.pages.dev/, scraped with Firecrawl). Used here with the owner's permission for this demo. `app/static/app.css` defines them as CSS custom properties on `:root`.

| Token | Value | Use |
|---|---|---|
| `--background` | `#F8F7F4` | page |
| `--surface` | `#FFFFFF` | cards |
| `--muted` | `#ECEAE6` | secondary buttons, chips |
| `--border` | `#E4E1DB` | hairlines |
| `--foreground` | `#1A1815` | ink, primary buttons |
| `--muted-foreground` | `#77746F` | secondary text |
| `--faint-foreground` | `#A6A29B` | `///` eyebrows, meta |
| `--inverse-highlight` | `#3A3631` | top of the primary-button gradient |
| `--accent-warn` | `#B4532A` | spikes, risk |
| `--accent-ok` | `#3F6B4E` | executed, learned |
| radius | `6px` buttons, `12px` cards | |
| type | Switzer (Fontshare) for text, Geist Mono for numbers and meta | |
| eyebrow | `/// LABEL`: uppercase 11px, tracking 0.08em, faint | section labels |
| buttons | `h-8`, 12px text, ink gradient for primary, muted gradient for secondary | |
